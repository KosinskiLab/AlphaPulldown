# af3x — Corpus File Map

Files in the corpus directories use hash-based names
(e.g. `0026fabb0ee59c81dd8700adf9234a3f.md`). This index maps
human-readable source names to those files. Each source has its
own file with paths/URLs, hash filenames, chunk counts, and token counts.

**Directories:**
- Normalized docs (full markdown): `/g/kosinski/dima/corpora/af3x/normalized/`
- Chunk text (smaller pieces): `/g/kosinski/dima/corpora/af3x/chunk_text/`

Read individual files for full document context.
Do NOT try to load an entire directory — it may contain thousands of files.
